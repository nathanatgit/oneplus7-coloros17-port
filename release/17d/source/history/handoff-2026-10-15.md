## 4. Useful live-debug recipes (root adb, permissive)

- Swap a system binary without flashing: `chcon` the copy in `/data/local/tmp` to the original label, then
  `mount -o bind copy /system/bin/x`, `stop x; start x`.
- Restart the whole framework: `stop; start` (adbd drops for ~1 min; SF bind mounts survive).
- Linker namespaces: `/linkerconfig/ld.config.txt` is tmpfs → edit with `sed … > tmp; cat tmp > file`.
- Hard-to-catch input: `getevent -lt /dev/input/eventN` (event0 = qpnp_pon/power, event1 = tri-state-key).
- **OLED care (user request):** whenever the UI is stuck on a static splash, blank it:
  `for b in /sys/class/backlight/*; do echo 0 > $b/brightness; done`.
- Git Bash → adb/wsl: always `export MSYS_NO_PATHCONV=1` (otherwise `/data/...` becomes `C:/Program Files/Git/data/...`).
- WSL loop mounts vanish when the VM idles; every scratch script re-mounts (`/mnt/plk` donor, `/mnt/los`, `/mnt/losv`).
