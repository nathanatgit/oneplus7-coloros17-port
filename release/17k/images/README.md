# External image files

The binary images and generated flash ZIPs are intentionally excluded from Git. Download the required source/build images from the Quark share below, then place locally built release outputs in this directory before running `scripts/package-release.py`.

- Share name as provided: `OnePlus ...S 17`
- Quick-open code: `/~fd683bWECM~:/`
- Share link: <https://pan.quark.cn/s/627ed80c325b?pwd=ZYAs>
- Extraction code: `ZYAs`

The share URL includes the extraction code. Anyone able to read a public copy of this file can access the shared files. Verify downloaded files against the SHA-256 values in `FACTS.md` and `packages/*/SHA256SUMS` before building or flashing.
